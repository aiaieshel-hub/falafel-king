# מלך הפלאפל

משחק דפדפן עצמאי בעברית. מגדלים חומוס, מטגנים כדורי פלאפל ומגישים מנות ללקוחות לפני שהם מאבדים סבלנות. מרוויחים כסף, קונים שדרוגים עם יתרונות ומחירים, עוברים שלבים ונהנים מזמן בונוס שבו כל מכירה שווה כפול.

## איך משחקים

פותחים את `index.html` בדפדפן. גוררים את הדמות בטלפון או בעכבר, או משתמשים בחצים או במקשי WASD. עוברים בשדה כדי לקטוף, עומדים בעיגול הכחול כדי להפקיד בתחנת הטיגון, אוספים בעיגול הירוק, ומפקידים בעיגול האדום ליד הדוכן. המכירות קורות לבד; אוספים את הכסף בערימה הירוקה. עומדים על עיגול שדרוג לקנייה, ויוצאים ממנו לפני קנייה נוספת. ההתקדמות נשמרת מקומית כשהדפדפן מאפשר זאת.

אין צורך בהתקנה, שרת או תלות חיצונית. לפרסום ב-GitHub Pages בוחרים בענף הראשי ובתיקיית השורש.
